# FullClock — Проекційний повноекранний годинник

Мінімалістичний та стильний повноекранний веб-годинник, оптимізований для використання як проектор або настільний дисплей. Створений на базі React, TypeScript, Vite та Tailwind CSS.

## Особливості проєкту

* **Мінімалістичний дизайн** — фокусується виключно на часі, має глибокий чорний фон без зайвих деталей.
* **Синхронність із системою** — завдяки використанню самокорегованого таймера, хвилини оновлюються синхронно із системним часом без дрейфу мілісекунд.
* **Повноекранний режим** — вбудована інтерактивна кнопка для перемикання у режим на весь екран (Fullscreen API).
* **Посилання на репозиторій** — швидкий доступ до вихідного коду безпосередньо з інтерфейсу.
* **Оптимізована PWA підтримка** — годинник працює в автономному (офлайн) режимі після першого завантаження.

## Структура коду (модульна архітектура)

Проєкт розбито на ізольовані частини:
* `components/Icons.tsx` — містить SVG-іконки керування (повний екран, GitHub).
* `components/Clock.tsx` — презентаційний компонент годинника з адаптивним масштабуванням тексту (`26vw`) та плавною анімацією появи.
* `hooks/useCurrentTime.ts` — кастомний хук для синхронізації часу.
* `App.tsx` — координує роботу станів, повноекранного режиму та розмітки.
* `index.css` — містить стилізацію та ключові кадри анімацій появи.

## Як запустити локально

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
3. Скомпілюйте оптимізовану збірку для продакшну:
   ```bash
   npm run build
   ```
