# FullClock

Мінімалістичний проекційний повноекранний годинник.

## Особливості

- 🕒 Перемикання 12/24-годинного формату часу
- ⏱️ Можливість увімкнення/вимкнення відображення секунд
- 🔲 Повноекранний режим
- 💾 Збереження налаштувань користувача

## Запуск

```bash
npm install
npm run dev
```
